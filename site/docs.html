Документация Windows-прототипа

CLI

Коннектор позволяет надиктовать и исправить сообщение, затем попробовать отправить его в открытую сессию Codex CLI. Распознавание выполняется на вашем ПК. Телефонный интерфейс и аккаунт находятся в разработке.

Быстрый старт

Текущий прототип рассчитан на Windows и Codex CLI в CMD или PowerShell. Нужны .NET 8, микрофон и локальные модели Vosk и Whisper. Локальная отправка в уже открытую вкладку работает без обязательного плагина, общего сервера Codex и перезапуска вкладки.

Исходники и команды сборки находятся в пакете Windows-коннектора. Публичного установщика пока нет.

Управление

  1. Откройте нужную сессию Codex CLI в CMD или PowerShell и выведите её вкладку на передний план.
  2. Ctrl + Alt + Пробел открывает основной ввод; удержание Ctrl + Alt + V запускает быстрый голосовой ввод, отпускание завершает запись.
  3. Произнесите сообщение. В основном окне можно проверить и поправить распознанный текст, а также выбрать другую обнаруженную сессию.
  4. Enter завершает запись и пытается отправить сообщение в выбранную сессию; кнопка «Отправить» оставляет окно открытым. Esc закрывает ввод без отправки.

Перед отправкой приложение повторно проверяет выбранное окно, вкладку и сессию. Если адресат не подтверждён, текст сохраняется для правки. Финальное распознавание длинной записи может занять время.

Куда попадает сообщение

Коннектор сопоставляет видимое окно терминала с открытой сессией Codex и перед вводом повторно проверяет адресата. Он вводит текст и один Enter в выбранную вкладку; получение сообщения дополнительно проверяется по истории именно этой сессии. К сообщению добавляется метка [via Voice Connector]. Постановка клавиш в очередь Windows сама по себе не считается подтверждением Codex.

Если вкладка недоступна или её нельзя однозначно подтвердить, коннектор не пытается отправить текст в другую сессию. Локальное распознавание речи не означает локальную обработку запроса моделью Codex.

Автопрослушивание ответов выбранной сессии и переход между ответами ещё не проверены в полном пользовательском цикле. Синтез речи выполняется локально на ПК.

Данные и доступ

Сейчас звук обрабатывается локальными моделями на ПК, а коннектор работает с открытой сессией Codex. Для доступа с телефона из любой сети разрабатываются отдельный аккаунт CLI, привязка устройств и зашифрованный канал для истории и сообщений. Сервер не запускает распознавание и команды Codex.

В тестовой сборке кабинета телефон записывает голос локально, передаёт его зашифрованным на подключённый ПК и показывает распознанный текст для правки. Отправка требует отдельного нажатия и разблокированного ПК с видимой выбранной сессией. При неясном результате автоматического повтора нет. Сервис пока не развёрнут.

Аккаунт CLI независим от аккаунта основной платформы AIQOO. Инструкция по подключению и отзыву доступа появится вместе с работающим сервисом.

Поддержка и ограничения

  • Windows + Codex CLI — единственный прототип на данный момент. Claude Code, macOS и Linux пока не проверены.
  • Короткие слова могут распознаваться неверно; проверяйте текст перед отправкой.
  • Телефонный доступ, публичный установщик и автоматическое обновление ещё не готовы.
