План

Windows-прототип

Три действия до отправки

Текст остаётся под вашим контролем до подтверждения.

01

Откройте вкладку

Выведите нужную сессию Codex CLI на передний план и вызовите коннектор горячей клавишей.

02

Скажите и поправьте

Речь распознаётся на компьютере. Полученный текст можно изменить прямо в поле ввода.

03

Подтвердите

Enter завершает запись и отправляет сообщение в выбранную сессию, когда адресат подтверждён. Если вкладка изменилась или недоступна, текст остаётся для правки. Esc закрывает ввод.

Архитектура

Где выполняется работа

Компьютер остаётся местом, где работает коннектор. Серверная часть нужна для доступа с другого устройства.

01 / На вашем ПКРаспознавание и работа с Codex

Микрофон и локальные модели обрабатывают речь. Коннектор пробует отправить текст напрямую в подтверждённую сессию Codex; при недоступности прямого канала текст остаётся для правки.

02 / Для доступа с телефона · в работеАккаунт, привязка и канал связи

Отдельный сервис будет связывать ваши устройства. Содержимое истории и сообщений планируется передавать в зашифрованном виде.
